The problem

Crop selection depends on multiple soil and climate factors. Interpreting these factors together can be difficult without a simple decision-support layer.

01

Too many variables

Nutrients, rainfall, temperature, humidity and pH all influence crop suitability.

02

Hard to compare

Manual interpretation makes it difficult to quickly compare several crop classes.

03

Need simple outputs

A useful prototype should turn raw measurements into a clear, understandable recommendation.

How it works

One simple flow from field measurements to a machine-learning recommendation.

01 · INPUT

Farmer data

Enter soil and climate values from a test or current observations.

02 · ANALYZE

ML model

A Random Forest classifier evaluates the seven parameters together.

03 · RECOMMEND

Crop classes

The model returns a ranked set of suitable crop classes.

04 · EXPLAIN

Understand

Present the result in a farmer-friendly format rather than raw model output.
